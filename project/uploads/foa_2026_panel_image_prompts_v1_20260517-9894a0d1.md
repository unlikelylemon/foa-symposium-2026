# FOA Symposium 2026 — Panel Image Prompt Set

Image generation prompts for every panel and event title slide in the 2026 deck. Each image will fill the left half of a 16:9 panel slide (4:5 portrait crop) with the content block on the right.

These prompts are deliberately written to produce a coherent series — eleven plus images that feel like they came from a single photographer's monograph rather than eleven separate AI outputs. Each panel's conceptual subject is rendered as macro photographic abstraction in the Ink + Brass + Bone palette, sitting in the same fine-art photography world.

**How to use**: Prepend the PREAMBLE block to each scene description before generating. The first prompt below shows the full concatenated version as a working example. The rest are scene-only for cleaner scanning. Generate the Heritage panel first as a calibration test before producing the full set. If that one lands, the rest will follow.

---

## PREAMBLE (prepend to every prompt below)

> Photographic abstract conceptual image. Museum-grade fine art photography quality. Cinematic Roger Deakins / Christopher Doyle aesthetic. Photographic realism only — NOT illustration, NOT 3D render, NOT digital art, NOT computer graphics. Warm shadow grading with antique brass highlights (#B8935A, matte antique gold, NOT bright yellow, NOT saturated). Deep warm near-black field (#0B0907, warm brown-black, NOT pure #000). Slight mid-tone desaturation. Subtle film grain 2–4%. Gentle vignette at edges. Portrait orientation 4:5 crop. No human figures or faces or recognizable people. No recognizable buildings or full architectural views. No tech clichés (no data swirls, no neural networks, no glowing UI, no holograms, no digital sparkles, no circuit boards). No bright gold, no yellow tones, no neon, no high-saturation accents. The image should feel like a still from a fine art photography monograph — atmospheric, restrained, considered.

*Maria Ahlström-Bondestam, Johannes Gullichsen · Multigenerational time, rooted permanence*

## Generation Notes

**Tool recommendations**: ChatGPT image generation (DALL-E 3 / GPT-4o image) and Midjourney v6+ both handle these prompts well. Midjourney produces more cinematic results out of the box but is less literal with prompt specifics. ChatGPT is more literal but sometimes flatter in mood. Generate the same prompt in both and pick the best result.

**Calibration test**: Generate Panel 2 (Heritage / tree rings) first. It's the most distinctive subject in the set and will tell you immediately whether the photographic realism + antique brass grading + macro abstraction is landing. If the result feels illustrative or digital-renderish, adjust the prompt before running the full set — try adding "shot on Hasselblad medium format film, scanned at high resolution" or "Kodak Portra 800 film stock" to push it further into photographic territory.

**Series coherence check**: After generating all 11, view them in a contact sheet (4x3 grid). They should all feel like the same photographer made them — same shadow density, same warm grade, same restraint. If one stands out as too bright, too colorful, or too literal, regenerate that one. Series coherence matters more than any individual hero shot.

**Iterate per panel**: Generate 3–4 variations per prompt before settling. Image gen has variance — the right shot is often the third or fourth attempt, not the first.

**Avoid these failure modes** (watch the outputs for):
- Bright yellow gold instead of antique brass — regenerate with stronger anti-yellow language
- Visible faces or hands sneaking into the frame — regenerate explicitly forbidding human elements
- Architectural elements becoming too readable as a specific building — push closer to macro abstraction
- "AI shimmer" or digital sparkle aesthetic creeping in — emphasize film grain and analog photography references
- Over-saturated colors — push desaturation and warm-grade language harder

**Resolution**: Generate at the highest resolution the tool supports (2048x2560 or higher for 4:5 portrait). The images need to render cleanly on a 4K presentation screen.

**File naming convention**: `foa_2026_panel_image_{nn}_{slug}_v{n}_{YYYYMMDD}.{ext}` — for example `foa_2026_panel_image_02_heritage_v1_20260517.png`.
